# PokeGo

A simple Pokémon app built with Expo, React Native, TypeScript, and Expo Router. It fetches the first 20 Pokémon from PokéAPI and displays their names, primary types, and front and back sprites in colored cards. Tap a card to open a details screen with the Pokémon’s name, type, image, and matching background color.

## Run locally

```bash
npm install
npm start
```

Open the app on your device or run `npm run web` to use it in a browser. An internet connection is required to load Pokémon data and images.
